# The Braille Lite releases the voices and the emulator know: one row per firmware image, keyed by its sha256 (the
# .BNS from 3000h, `length` bytes).  gen_languages.py turns it into bl_languages_table.h, which bl_firmware.c reads
# (its list: blv_import_firmware, blv_state_check, blv_release_*); `python gen_languages.py --check` fails when the
# header is stale (run_tests).  A release is listed only once it was booted through its recipe and its state hashed;
# the row's every column is what the unit itself showed, never a guess.  The list is what the apps can RECOGNISE, never
# what they offer: a voice or an emulator unit is offered only for a release the user imported (or whose firmware is in
# the firmware folder).  Within one voice the newest release comes first: the importers keep the first when a user
# brings two.
#
# Columns, separated by |:
#   id      the release's own name, stable once shipped (a state file or a voice may carry it)
#   model   bl = Braille Lite 2000, bns = Braille 'n Speak 2000 (bl_model)
#   tag     its language (BCP 47)
#   voice   the voice's language (bl_firmware.h BLV_FW_*: english, spanish, german, italian, slovak), or - when
#           the release is the emulator's only (blv_import_firmware then refuses it for a voice)
#   shape   its state recipe (bl_state.h BLV_SHAPE_*): english = three power-ons, the answers early;
#           slow = one long power-on, twelve answers 80 million instructions apart
#   yes     the letter that answers the setup's questions, as the unit asks for it (a-z, computer braille)
#   cp      the unit's DOS code page for its text and file names (850, 852), as read from what it says for its own
#           accented letters; - when not yet read
#   length  the image's length in bytes
#   image   sha256 of the image
#   state   sha256 of the state blv_make_release_state makes from it (MAME's Z180: the same bytes on every platform)
#   label   what the import says it found
#
# The June 5, 2003 English: "FS june2003" -- blt2000.exe (a zip behind its code) and its BL2ENG.BNS; the NVDA add-on's.
# The September 20, 2000 English: ONCE's "braillehablado" disk, blite2000/BL2ENG.BNS: the English recipe fits it (its
#   prompts during the recipe are June 2003's but for one power-on sentence).
# The September 20, 2000 Spanish ("versión del 20 de Septiembre de 2000 ver. a"): ONCE's disk, blite2000/BL2SPA.BNS;
#   the Spanish unit's reset (bl2spa_fresh.state).
# 0.8: Blazie's September 2000 update disk, German and Italian (an anonymous donation): each heard -- "zwei tausend
#   bereit", "due mila pronto" -- and speaking its own language through the voice.  The Slovak Braille 'n Speak 2000
#   (the Slovak community's BS2SLL.BNS).
